# Kadad Class

پلتفرم کلاس آنلاین کاداد (`class.kadad.ir`).

## وضعیت

این مخزن فعلاً اسکلت اولیه پروژه است و برای توسعه روی PHP 8.1 و Laravel آماده می‌شود.

## ساختار هدف

- `app/` — منطق اصلی برنامه
- `bootstrap/` — bootstrap برنامه
- `config/` — تنظیمات
- `database/` — migrations و seeders
- `public/` — document root وب
- `resources/` — view و assetها
- `routes/` — routeها
- `storage/` — فایل‌های runtime
- `tests/` — تست‌ها

## محیط استقرار

- Domain: `class.kadad.ir`
- PHP: 8.1
- Repository: GitHub
- Deployment: cPanel Git Version Control
